动态限速与机器人场景模拟插件

目标每秒刻数 · 可回滚负载 · 机器人模拟 · 状态坐标

用可控压力复现卡顿和攻击场景

每秒刻数压测面向测试服和管理演练，提供每秒刻数动态限速器与真实实体机器人场景模拟。它会在远离玩家的位置制造可回滚压力，并允许管理员随时查看状态、坐标或彻底停止清理。

插件介绍

它适合测试服、压测环境和应急演练，不建议在正式玩家活动高峰随意启用。插件重点是用可观察、可停止、可恢复的方式制造压力，帮助管理员验证监控、告警和优化策略。

核心能力

每秒刻数动态限速

使用 /tpslag start 指定目标每秒刻数，并动态调节压力强度。

多类型负载

组合 CPU 计算、内存分配、区块读写和主线程延迟。

远离玩家执行

默认在远离出生点的强制加载区块制造压力。

机器人攻击模拟

使用 /abot 创建真实实体，模拟大量机器人冲击与加入消息。

状态与清理

支持查看状态和坐标，停止时清理任务、方块和运行状态。

压测流程

一

设定目标

使用 /tpslag start 后附目标每秒刻数，或按配置启动。

二

制造负载

插件在指定区块执行计算、读写和延迟压力。

三

观察状态

通过 /tpslag status 与 /tpslag pos 查看当前情况。

四

停止回滚

执行 /tpslag stop 或 /abot stop，清理并恢复现场。

运行信息

支持平台

面向纸端一点二十一点四环境。

主命令

使用 /tpslag 管理限速，使用 /abot 管理机器人场景。

权限节点

tpslag.control 控制压测，tpslag.abot 控制机器人模拟。

使用提醒

请优先在测试服使用，并在压测前确认备份与监控。

压测完成后务必执行停止命令，并检查强制加载区块、机器人实体和状态输出是否已经清理。
